## Steps To Run This Application:

### 1. Clone the Repository

Open your terminal and run the following command to clone the repository:

    git clone https://github.com/xxstraky/CS157C-team2.git


Then navigate into the project folder:

    cd CS157C-team2


### 2. Install NPM if you don’t have it
    
If you don’t have NPM (Node Package Manager), install it through this website: https://nodejs.org/ 


### 3. Install Dependencies

In the root folder ( CS157C-team2\ ) of the project, run:

    npm i

This command installs all necessary dependencies to run the application.


### 4. Start the Backend

Navigate to the backend folder in your terminal:

    cd backend

and start the Redis-connected server with:

    nodemon server.js



### 5. Start the Frontend

Open a new terminal, return to the root folder ( CS157C-team2\ ) of the project, and run:

    npm run dev



### 6. Access the Game

Open your browser and go to http://localhost:8080/

You should see our home page.
